## 0.0.1

* **Initial Production Release (SY-2139 Protocol Component)**
* Added **SycoreVault**: Secure local storage for ECC/Ed25519 keys using `flutter_secure_storage`.
* Added **HosnEngine (堡垒)**: Implementation of 1-to-1 E2EE using X25519 and ChaCha20-Poly1305.
* Added **SamamEngine (صمام)**: Group/Team data encryption using AES-GCM and Master Key wrapping.
* Added **JahrEngine (جهر)**: Public data integrity with Ed25519 digital signatures.
* Added **SycoreClient (The Maestro)**: Unified API client for easy integration.
* Added **Real-Time Synergy**: Full WebSocket support for live domain event listening.
