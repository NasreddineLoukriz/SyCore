# SYCORE SDK (Flutter/Dart)
هذا الـ SDK يطبق قواعد **بروتوكول SY-2139** (Zero-Trust BaaS).  
المبدأ الأساسي: **"الخادم غبي، والعميل ذكي وأمين".**  
البيانات لا تخرج من جهاز المستخدم إلا وهي مشفرة (E2EE) أو موقعة رقمياً.

## المحركات الثلاثة:
1. **حِصْن (HOSN):** تشفير 1-to-1 لا يمكن حتى للسيرفر فكه (E2EE).
2. **صَمام (SAMAM):** تشفير مؤسسي للمجموعات بـ Master Key.
3. **جَهْر (JAHR):** نشر علني مؤكد عبر توقيع Ed25519 لمنع التزييف.
