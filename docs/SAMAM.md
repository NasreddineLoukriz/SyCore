# 🛡️ SAMAM Engine
## Group Blind Encryption
**Secure Team Collaboration on a Zero-Trust Server**

---

## 🎯 The Concept

**SAMAM** is the SYCORE Framework's cryptographic pattern for **Group-Based Secure Data Sharing**.

Unlike HOSN (which is strictly 1-to-1), SAMAM allows multiple authorized team members to access encrypted data efficiently. 

**Why "Blind Encryption"?** 
The server remains completely blind to the contents. We use the term "Blind Encryption" instead of pure academic "End-to-End Encryption" (E2EE) to be transparent: keys are shared among a trusted group, not just two endpoints.

---

## 🔑 How it Works: Key Management

At the core of SAMAM is the **Group Master Key**.

- **The Master Key:** A symmetric key (e.g., AES-256) is generated by the creator for the group, team, or workspace.
- **Key Wrapping:** This Master Key is encrypted (wrapped) individually for *every* authorized member using their respective Public Key (ECC X25519).
- **Storage:** The Zero-Trust Server stores the encrypted application data, alongside a list of these wrapped Master Keys. It never sees the raw Master Key.

---

## 🔄 Data Flow: Sending & Receiving

**📤 Sending Data:**
1. A user encrypts a file or JSON payload using the **Group Master Key**.
2. The user sends the single blind ciphertext to the server.

**📥 Receiving Data:**
1. A team member fetches the ciphertext from the server.
2. The SDK retrieves that user's specific **Wrapped Master Key**.
3. The SDK unwraps the Master Key using the user's local Private Key.
4. The SDK decrypts the data layer transparently for the UI.

---

## 👥 Adding & Removing Members

Managing access is handled strictly by the "Smart SDK," not the DB roles:

- **Adding a Member:** An existing admin fetches the new member's Public Key, encrypts the current Group Master Key with it, and uploads this new Wrapped Key to the server.
- **Removing a Member:** To ensure forward secrecy, the group must rotate keys. A **New Master Key** is generated and wrapped *only* for the remaining members. Past data remains encrypted with the old key, but all future data uses the new one.

---

## ✅ Summary

**SAMAM** provides scalable privacy for teams. It allows rich collaboration (like shared workspaces, enterprise chats, or medical records) while strictly enforcing the SY-2139 Protocol: **The server is a generic vault and cannot read your data.**
